# wQFM-rs artwork

The wQFM-rs icon shows a weighted quartet ab|cd: the two sides of the
taxon bipartition in teal and indigo, joined by the weighted middle edge
in amber to orange. It belongs to wQFM-rs (not to Q-MAWS or wQFM).

| File | Use |
|---|---|
| `icon/wqfm-rs-icon.svg` | source of every size |
| `icon/wqfm-rs-{32,64,128,256,512}.png` | README, docs, GUI |
| `icon/wqfm-rs.ico` | Windows (16 to 256 px); a copy in `crates/wqfm-cli/assets/` is embedded in `wqfm-rs.exe` |
| `social-preview.svg`, `social-preview.png` | GitHub social preview (1280 x 640; uploaded in the repository settings) |

The PNG and ICO files are rendered from the SVG with resvg. Licence:
Apache-2.0, like the rest of the repository.
