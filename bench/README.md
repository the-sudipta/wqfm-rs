# The wQFM-rs benchmark

The plan is fixed in `PREREGISTRATION.md` (with its amendments); the data
and tools are listed with SHA-256 in `DOWNLOADS.md`, `datasets.tsv` and
`tools.tsv`. Every method runs in WSL Ubuntu 24.04, one run at a time, with
nothing else running on the computer.

| Script | What it does |
|---|---|
| `config.sh` | paths and limits (6 h, 20 GB per file, Java heap 6 GB) |
| `setup_tools.sh` | unpacks and builds every method into `tools_built/`, writes `versions.tsv` |
| `prepare_inputs.sh` | writes the inputs S2, S3, G1, G2 (and G3) into `inputs/` |
| `jobs.py` | writes the job list: every input with every method |
| `run_jobs.sh` | runs the jobs, restartable, under the limits; `results/results.tsv` |
| `analyse.py` | H1, H2, H3 and the descriptive comparison; tables and a figure |

## Steps

On Windows (the Linux build of wQFM-rs and of its input generator):

```bash
RUSTFLAGS="-C linker=rust-lld" cargo build --release --locked \
  --bin wqfm-rs --example make_inputs --target x86_64-unknown-linux-musl
```

In WSL (`B=/mnt/d/_external/wqfm_bench`):

```bash
bash bench/setup_tools.sh target/x86_64-unknown-linux-musl/release/wqfm-rs
bash bench/prepare_inputs.sh
python3 bench/jobs.py $B/inputs $B/results/jobs.tsv
bash bench/run_jobs.sh $B/results/jobs.tsv
python3 bench/analyse.py $B/results/jobs.tsv $B/results/results.tsv \
  $B/tools_built/wqfm-rs $B/results/analysis
```

S1 inputs are generated by `run_jobs.sh` just before they are used and
deleted afterwards; they are deterministic (`make_inputs`, seeds 1 to 5),
and the runner records their quartet count and the score of every output.

## Test of the scripts (2026-10-26)

Before any benchmark run, the scripts were run end to end on tiny inputs
(a 25-taxon generated input, one wQFM example file, wQFM's 11-taxon gene
trees) in a separate folder. This found and fixed: Windows line ends in the
scripts, a missing quartet count for deleted S1 inputs, a misleading H2
verdict when no input qualifies, and the 32-bit PAUP* of wQFM-TREE, which
WSL1 cannot run (Amendment 1, item 3). The times of that test are not
benchmark results.
